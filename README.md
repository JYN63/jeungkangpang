# 증강팡 · Augment Pop

애니팡처럼 맞추고, 증강을 골라 더 멀리 가는 매치-3 퍼즐. made by 이정연

- 플레이: https://jyn63.github.io/jeungkangpang/
- 휴대폰에서 열고 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요 (한 번 연 뒤에는 오프라인에서도 실행).

## 사용한 소리
- 몽환곡 악기 소리: FluidR3_GM 사운드폰트 (CC BY 3.0)
- 꽃가마 행차의 가야금·대금·장구 소리: 국악방송 「교육용 무용 반주음악_기본장단」 (공공누리, 출처 표시·비상업적 이용)
